# Tutorial artwork

The four demonstration songs are Desultory Signals (DS), Exoplanetary Mirage (米垃圾), Entrance to the Chaos (超市入口), and ハテ (8000). Each uses unchanged EZ, HD, IN, AT and original assets copied from storage/corpus. No live match or user data is included.

Titles, aliases and hints come from storage/corpus/catalog.json. Second-song training explicitly accepts 米垃圾 as an alias for Exoplanetary Mirage.
