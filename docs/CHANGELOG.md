# 更新记录

## 0.3.1 Preview — 2026-10-27

- 修复 HTTP 生产入口缺少 Clipboard API 时复制房间码报错的问题，兼容选择复制和浏览器拒绝权限的情况，失败时显示提示。
- 噪域输出按画布实际的 Alpha 格式显式编码，统一 Chrome 与 Edge 的透明层合成，保持 Edge 的粉红区透明度与颜色，避免部分合成路径下异常发亮。
- 手机端隐藏全屏切换按钮，继续使用横屏提示和受支持浏览器的横屏开始操作；沿用原有布局和元素比例，仅扩展透明触控范围。
- 适配安全区、动态视口和软件键盘；输入时保持画布比例，通过整体视口滚动显示输入框，关闭键盘后恢复原位置。
- 房间人数拖条按结束时的实际值提交；输入关闭自动纠错和大小写替换，避免中文输入法尚在选词时提交。
- 噪域在弹窗和后台暂停绘制，关闭后恢复当前进度；未出现噪域时跳过布局和纹理准备，离屏曲目不参与噪域绘制，血条复用尺寸缓存。保留渲染清晰度、60fps 目标与原有计时、计分和命中规则。

## 0.3.0 Preview — 2026-10-27

- 接入多人房间、实时榜单、固定题数同步跳过及 Infinity 独立进度与总时限；支持死亡后回血到 10HP 复活计分。
- 房主可在玩家卡片上移出成员或转交房主，房间设置支持曲目范围；转交后提示新房主，比赛中转交延后到返回房间时提示。房主卡片增加线条流光与粒子效果，玩家操作层半透明淡入并保留底下的玩家信息。
- 房间成员卡片展示对应难度的 Infinity 最好成绩牌：IN 使用 IN，其他难度使用 AT；汇总不同设置下已公布的当前规则成绩。操作层下面加入轻微模糊。
- 房间与两页设置共用主界面 BGM，三页均显示可复制的房间码。底部设置摘要按变化逐项或单项向右滑动淡入淡出，游戏时限也使用相同的出现和退出动画；房主特效在转交后渐显。
- 创建、加入、返回和退出房间统一淡黑时长；转场中途刷新仍保留房间入口，重新加入同一房间后不会被旧一局的迟到请求移出。成员长名字完整换行，卡片按内容增高。
- 首图加载满 60 秒房主可强制开始，满 90 秒自动开始；仅已加载者参赛，未加载者退出房间并返回主菜单。加载失败的房主可返回主页并自动转交房主；移出者可加入其他未开局房间。
- 多人生产入口默认启用，支持构建时关闭；升级有安全公告的请求解析、上传、地址解析与校验依赖，并拒绝压缩 JSON 请求体。

## 0.2.1 Preview — 2026-10-26

- 计分规则升级为 `v5-hint85`：第三条提示统一为“得分减少，难度下降”，实际得分以原难度满分的 85% 为上限，题目应得满分和结算分母保持开局难度；同步新手教程、正式判题与规则文档，旧成绩不重算，旧规则成绩保留在同一榜单并显示“--”，新规则重新排名；新成绩公布后替换同一玩家同条件的旧榜单成绩。
- 修复上一题提交或补拉请求延迟时，下一题继续显示“提交中”并禁用输入框的问题；提交锁按题目及请求隔离，过期响应不会覆盖新题状态。
- 在“新手教程”左侧新增“跳过难度选择过场”开关，复用设置开关样式并保存偏好；开启时日常游戏确认开始后以统一时长淡黑，再加载题目，新手教程保持原流程。
- 前后端、全部工作区、锁文件和文档版本统一为 0.2.1 Preview。

## 0.2.0 Preview — 2026-10-23

### 2026-10-26 修正

- 游戏内特殊范围提示统一为“愚人节曲目/特殊曲绘”，同步已有解锁提示。

- HD/IN/AT 改为从 EZ 实时生成，按回合持久保存来源、随机种子与算法版本；同题主图与降档提示共用生成过程，每局使用独立缓存目录。
- 开局黑屏先生成最多 10 道题，首题下载解码后才计时；答题中补足包含当前题的 20 道待答题，满额暂停，后续题提前加密传输。
- 补收 291 张非主线及特殊 Raw：254 张通过图像模型去除曲名/作者，35 张直接复用为 EZ，2 张采用用户提供的去字成图。可玩曲库增至 339 首、351 组；源文件统一为无损 WebP。
- 非主线范围提示改为包含首次收录版本的连续 2～3 个版本，已删除曲目标记“已删除”，愚人节变体仅显示“愚人节曲目”。分类按曲绘变体保存。
- 修复预载失败后不能重试、本地 localhost 与 127.0.0.1 不一致导致实时连接拒绝，以及跳过时因截止时间变化而重播曲绘动画的问题。

- 单人游戏展开曲绘/谱面选项；谱面暂不可选。齿轮展开曲绘范围，支持主线、非主线、已删除、愚人节多选，主线/非主线至少保留一项。
- AT 强制使用全曲库，不受范围勾选影响；警告文字显示“范围全曲库 血条强制开启”。
- 更新全部工作区、锁文件、前后端版本显示与健康接口为 0.2.0 Preview。

## 0.1.1 Preview — 2026-10-11

- 新增 16 步交互新手教程，直接使用正式的难度选择、猜曲和结算界面；提供四首歌曲的真实四档曲绘、原图、曲名与别名。教学请求和身份由独立的本地运行时处理。
- 用字幕、收缩圆圈、欢迎和结束黑屏，引导放大曲绘、提示、错答扣血、答对回血、别名、跳过、噪域与放弃挑战。只有当前练习目标接受操作。
- 将“新手教程 →”放到玩家资料卡右下角，教程与登出按钮采用主题平行四边形，两者右侧斜边对齐。
- 错答练习中提交正确曲名或别名时，将输入按随机字位变成乱码后按错误答案处理；大号红色字幕用 AT 相同的随机逐字效果显示反馈，随后继续教学。
- 结算中分七段解释计分、耗时、错答、提示和综合成绩牌；点击画面快速切换下一段，保留自动播放，并防止连点跳过多段。
- 刷新教程时恢复步骤、题目、提示、血量、成绩、输入草稿和结算讲解；仅使用当前标签页的临时恢复数据。关闭后重新打开回到游戏主界面，重新进入教程从头开始。
- 统一前端显示为 `0.1.1 Preview`，根包、各工作区、锁文件及健康接口使用 `0.1.1-preview`。前后端应用版本均从根包的版本字段读取。
- 整理 README、文档索引、API、架构、素材、部署与参考动效说明，补充教程运行时、计分和刷新恢复测试，以及 GitHub CI。

### 同版本修正

- 教学原图改用无损 WebP，保留 2048×1080 分辨率并验证解码后的像素与 PNG 完全一致；在猜题时提前下载并解码，答对或点击时复用已准备的图片，保留原有延迟与动画，教学流程不增加等待。
- 教学图片在猜题与结算间共享下载和缓存，避免同一原图重复传输；取消单个画面不打断共享请求，加载失败可重试，退出教程时清理。
- 手机浏览器和触摸设备自动跳过鼠标悬停扣血教学，保留点击噪域步骤；桌面继续展示悬停教学。
- 手机噪域以 60fps 为目标统一更新图层与合成，限制高 DPI 缓冲和总像素数，并接通共享渲染器的自动降画质；桌面同样以 60fps 为目标，红区命中、伤害与计时规则保持一致。
- 手机和电脑共用的噪域 shader 按有效区域数量计算，并裁掉空白绘制范围；低性能设备可自动降到 0.35 倍缓冲，合成纹理同步缩小，保持 60fps 目标与原有命中规则。

- 结算复用猜题阶段的题图文件，提前加载附近两屏并优先处理当前屏幕；已加载行滚出后继续保留，移除曲绘与原图的加载提示条，保留失败重试。题图缓存限制为 16 MiB，按账号、比赛、题号与难度隔离，退出结算时释放。

- 补入用户提供的 Break Over、MARENOL 去字成图；本地曲库增至 339 首、351 组，非主线 291 张 EZ 全部就绪。
