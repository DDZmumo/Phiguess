# EZ 基底实时题图

正式 HD、IN、AT 题图由 `packages/game-core/artwork/engine.mjs` 从无损 EZ 基础图生成，EZ 展示图和原图沿用现有资源。算法版本 `ez-regions-v1` 固定采用用户确认的 v6 参数：HD/IN/AT 为 60/18/6 个色块，14/7/4 色；IN/AT 进一步简化边缘，随机强度为适中档。

## 生成与权限

- HD 一次生成 HD，降档提示复用 EZ；IN 一次生成 HD/IN；AT 一次生成 IN/AT。同题两档共享分区、合并链和随机种子。
- 每个比赛、题号在 `match_artwork_recipes` 保存随机种子、EZ 来源 ID、算法版本及缓存文件键。多人使用同一份题图，刷新不会重新抽图。
- 单个持久 Worker Thread 执行 CPU 算法，图像读取和生成不占用游戏状态串行队列。当前请求优先于后台预生成，等待队列最多 64 项，单任务超时 15 秒。
- 开局先生成 `min(10, 总题数)` 组；黑屏显示加载提示，首题下载并解码后通过 ready 握手启动 3 秒倒计时。答题时顺序补足包含当前题在内的 20 道待答题，达到上限停止，进入下一题再补一道，剩余不足 20 道只计算剩余题目。后续组未就绪时延长揭晓阶段，不提前启动下一题计时；连续三次失败则中断本局，不额外扣血。
- 下一题在当前题正式开始且题图已解码后使用 gzip + AES-256-GCM 预载；失败请求清除并间隔重试，成功请求复用，避免黑屏阶段的 403 阻止后续预载。明文和密钥只在该回合开放后可取。降档、原图、结算接口继续验证参赛者权限。
- 已保存结算按原种子恢复题图；缓存缺失时重建。迁移前的旧记录第一次读取时生成并保存配方，成绩保留，未猜中题图改为新算法效果。

## 缓存与部署

`GENERATED_ASSET_DIR` 默认 `storage/generated`，每局使用 `<matchId>/` 独立目录，教程使用 `tutorial/` 目录，是可回收的 SVG 缓存；`GENERATED_CACHE_MIB` 默认 512。写入采用临时文件和重命名，整组写完才提交缓存键；每分钟最多触发一次按最早生成文件回收，目标容量 512 MiB。持久配方和不可变 EZ 来源保留，因此删除生成缓存不会改变后续重建结果。升级算法时必须保留旧版本实现，或先迁移旧配方，不能复用旧版本号改变参数。

原生 systemd 部署需创建 `storage/generated` 并授予 `phiguess` 写权限，同时加入 `ReadWritePaths`。Compose 使用独立 `generated_artwork` 卷。Worker 加载仓库中的 `packages/game-core/artwork/*.mjs`，发布时这些文件必须与后端构建来自同一提交。

## 素材迁移

先备份数据库、`storage/assets` 和当前构建，停止旧实例后执行迁移：

```sh
node --env-file=.env dist/tools/migrate.js
node --env-file=.env dist/tools/migrate-dynamic-artworks.js --apply
```

迁移为现有版本补充无损 EZ 来源和关联；验证来源文件存在后，解除旧高难度静态文件引用，再删除未被任何原图、EZ 或其他记录引用的旧 SVG。迁移报告写入 `output/retired-artworks-*.json`；`unmapped` 必须为 0，才可认定全库已切换。不带 `--apply` 只检查待退役运行文件。

源曲库清理由 `node tools/retire-static-corpus.mjs --apply` 完成：逐项列出 HD/IN/AT 源图、描摹输出及旧教学 SVG，核对路径与哈希后删除，并验证全部 Raw/EZ 哈希未改变。`prepared` 目录仅保留导入清单。

## 教程

教程 HD/IN/AT 通过限定四首教学曲目的 `/api/tutorial-art/:slug/:difficulty` 获取。每首使用固定种子与同一算法生成，不创建比赛、成绩或配方数据库记录；EZ 与原图继续从教学静态目录加载。公共教学接口不接受任意歌曲 ID、文件路径或随机种子。

## 验证

新增集成测试覆盖仅 EZ 的导入、多玩家题图一致、提示对应、未来题图权限、加密预载、重启恢复、缓存删除后复现、EZ 字节不变和旧资源退役保护。预览工具继续支持第九章样图对照。生成器切换不重算旧成绩。当前计分规则为 `v4-downgrade`：降档提示降低实际计分上限，结算满分仍按开局难度；旧规则成绩在同一榜单显示“--”，新规则成绩重新排名。
