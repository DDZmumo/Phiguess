# EZ 基底随机抽象样图

运行 `npm run preview:abstraction` 后打开 `http://127.0.0.1:5177`。

正式发题的生成单位应包含当前题图和降档提示图：HD 生成 HD 并复用已有 EZ；IN 一次生成 HD/IN；AT 一次生成 IN/AT。同题两档共用 EZ 输入、种子、分区和合并链，性能应按整组测量。预览一次生成三档仅为并排比较。

当前展示第九章的全部可用曲绘（含同曲不同曲绘版本），每套三个固定随机种子；原先三首示例排在前面。EZ 文件逐字节复制；HD/IN/AT 由 EZ 像素生成，不读取旧高难度 SVG。正式发题使用同一版本化引擎；此预览页只生成本地样图，不创建比赛或修改数据库。

实验算法使用带种子扰动的连通区域生长、基于颜色与邻接关系的分层合并、调色板聚类和轮廓简化。三档从同一次分区逐级合并，当前目标分别为 60/18/6 个色块、14/7/4 种颜色。v2 将 v1 的 IN 移到 HD、AT 移到 IN，新 AT 进一步合并并简化轮廓。参数用于视觉比较，尚未校准为正式游戏难度。固定输入、种子和依赖版本下结果可复现。

v3 保留色块数量和调色板，仅将 IN/AT 轮廓简化容差提高到 5/9 个处理像素；微小轮廓简化为三角形，避免重新保留全部锯齿顶点。v3 的 HD 保持 v2 的效果。v4 在此基础上将 HD/IN/AT 色块数量进一步降低为 60/18/6，沿用各档轮廓简化容差。

v5 增大初始分区位置扰动和合并代价的种子扰动，并加入平滑的局部偏好场，让不同种子在不同位置保留细节；色块数量、调色板上限与简化程度保持 v4 设置。预览增加同一难度的三种子并排对照。

v6 将随机性回调到 v4 与 v5 之间：分区位置扰动 0.8、合并噪声 1.3、局部偏好 0.45，紧致度仅上下浮动 10%；维持 60/18/6 色块和已有边缘简化参数。

样图生成到忽略目录 `output/ez-abstraction-preview`。构建时检查 EZ 字节一致、生成 SVG 静态子集、不同种子差异、相同种子可复现及三档复杂度递减。页面显示本机生成时间与 SVG gzip 体积；线上耗时需在服务器单独测量。
