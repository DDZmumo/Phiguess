# Phiguess

当前版本：**0.2.1 Preview**（包版本 `0.2.1-preview`）。更改详情见 [更新记录](docs/CHANGELOG.md)。

资料卡“新手教程”左侧提供“跳过难度选择过场”开关，默认关闭并保存到当前浏览器。开启后，日常单人游戏点击“确认并开始”会以其他界面相同的淡黑时长进入题目加载界面；新手教程按原流程播放。

Phiguess 是一个参考 Phigros 界面与动效的曲绘猜歌网页游戏。玩家根据不同抽象程度的曲绘，在限定时间内输入歌名或别名，完成单人挑战或无尽挑战。

仓库已包含前端、后端、素材导入工具、数据库迁移、部署配置、音频和猜曲素材：339 首歌曲、351 组 Raw／EZ 曲绘。HD／IN／AT 从 EZ 实时生成。克隆后可以直接启动本地预览，数据库和运行图片会在本机生成。

当前支持游客、玩家名／密码登录、排行榜、设置与最终结算。多人入口显示“多人房间（待开发）”，暂不可点击；底层房间接口与测试仍保留。项目持续开发中。

技术：React、Vite、Zustand、GSAP、TypeScript、NestJS 11、Socket.IO 4、PostgreSQL 17、Caddy。数据库使用 `pg` 参数化查询、事务和版本化 SQL 迁移。

## 直接预览（无需 Docker）

需要 Node.js 22.14+。以下为 Windows PowerShell 命令；其他系统将 `npm.cmd` 替换为 `npm`。

```powershell
git clone https://github.com/DDZmumo/Phiguess.git
cd Phiguess
npm.cmd ci
npm.cmd run preview:game
```

打开 `http://127.0.0.1:5174`（开发环境也兼容同端口的 `localhost`）。首次安装会下载对应平台的 PostgreSQL 二进制开发依赖；首次预览会迁移数据库并导入仓库中的曲绘，后续启动复用已有数据。

预览同时启动 PostgreSQL（55433）、后端（3000）和 Vite（5174），不创建系统服务。真实曲库使用 `phiguess_local` 数据库，生成后的运行图片位于 `storage/assets/`，数据库位于 `storage/preview/db/`。按 Ctrl+C 停止，数据会保留。

```powershell
# 使用其他前端端口，后端 CORS 与 Socket.IO 来源同步配置
npm.cmd run preview:game -- --port=5180

# 使用独立的合成演示曲库，不与真实曲库混用
npm.cmd run preview:game -- --demo
```

没有完整曲库时会自动使用合成演示库，并显示演示标识。本机连接配置保存在被忽略的 `storage/preview/runtime.env`，不随仓库上传。

启动页进入账号主界面后，可选择游客或登录。点击“单人游戏”先展开“开始”，再次点击淡黑进入难度选择；点击空白可以收回。选择难度后，字母移到中间，挑战设置从黑暗中浮现；确认后继续过场并开题。已有进行中的挑战可通过“继续上次挑战”恢复。

## 已实现

### 账号与主界面

- 游客填写玩家名即可进入；登录填写玩家名和密码，未注册的名字自动注册，已注册的名字验证密码后登录。游客同样可以参加排行榜。
- 玩家名最多 24 个字符，密码 8–128 个字符。登录名按 NFKC 和小写归一化；注册账号改名后，使用新名字登录。游客与同名注册账号保持独立身份，不自动合并成绩。
- 密码以独立随机盐的 scrypt 摘要保存；会话使用随机 Bearer token，数据库只保存 token 哈希，30 天有效，可注销。
- 支持更换头像，接受 PNG／JPEG／WebP，最大 3MiB；资料和头像保存在服务端。
- 游戏、排行榜、设置为三个可切换页签。设置包含界面动效、背景亮度、交互音效、音效音量与音乐音量，并自动保存在当前浏览器。
- 排行榜与设置内容在底部分隔线处裁切，超出区域不显示；只在内部滚动，隐藏滚动条，页面外层固定。排行榜的筛选项与表头不随名单滚动。
- 手机竖屏时显示横屏提示并阻止操作游戏；支持的浏览器可点击“横屏开始”进入全屏并锁定横屏，不支持时需手动横放手机。启动页与玩家资料卡使用原图库背景，减少动态效果时保留必要的操作与状态反馈。

### 交互新手教程

- 主界面玩家资料卡右下角的“新手教程 →”可进入教程，无需建立玩家档案。刷新保留当前步骤、答题与血量、输入草稿和讲解段落；仅使用标签页的临时恢复数据。关闭网页后重新打开会回到游戏主界面，不保留教程进度。
- 桌面 16 步、手机 15 步练习直接复用正式的难度选择、挑战设置、猜图与结算组件，配合字幕和收缩圆圈指引操作大图、提示、答错回血、二次确认跳过与放弃挑战。通过手机浏览器标识与触摸输入能力检测，手机跳过鼠标悬停扣血步骤，保留点击噪域教学。真实噪域、血条、音频与揭晓动画照常渲染；教学血条上限 20，初始 12HP。
- 进入教程先淡入黑屏显示欢迎文字，再淡出到难度选择。「确认并开始」后设置文字遁入黑暗，通过黑屏淡入猜图，跳过滚动文字过场；正式游戏仍保留原过场。
- 教学原图使用无损 WebP，保留 2048×1080 分辨率并验证解码后与 PNG 逐像素一致；源 PNG 保留。猜题时提前下载并解码原图，答对或结算点击后复用已准备的图片；保留 0.45 秒延迟与原有揭晓动画，教学流程不增加等待。同一原图在猜题和结算间复用下载结果，失败时可重试，退出教程时释放缓存并取消请求。
- 正式游戏与教程在猜题和结算间共享已下载、已解码的原图；进入结算后按题号预载未猜中的原图，点击前仍隐藏正确曲名。原图缓存以 32 MiB 为上限按进入顺序淘汰，退出该局结算时清理。题图以 16 MiB 文件缓存复用猜题阶段的下载结果；结算提前准备附近两屏，当前屏幕优先于附近图片和后台原图。曲库 Raw/EZ 源文件改用无损 WebP，导入器继续生成缩小的有损运行图片；详见 [素材说明](docs/LOSSLESS-ASSETS.md)。
- 「试一次错误答案」阶段若提交正确曲名或别名，输入内容会按随机字位变成乱码，再按错误答案扣 1HP；下方红色乱码以 AT 提示的随机逐字效果显示「我叫你输入错误答案你燕京侠吗？」，随后继续正常教学。减少动态效果时直接显示最终状态。
- 教学使用底部居中的淡入字幕；大圆从屏幕外收缩为目标位置的小圆，并闪烁指示。操作练习只允许操作当前指示的控件；自动检测完成操作，字幕淡出后进入下一步，无需点击教学的下一步按钮。最后结算将难度满分、耗时扣分、答错扣分、算分示例、提示与综合牌规则拆成 7 段在屏幕中央自动淡入淡出，约 30 秒；此时点击画面可快速淡出当前段落并显示下一段，切换完成前的连续点击不会跳过多段。综合牌使用实际组件演示，原结算画面保持不动；结束后淡入黑屏显示结束文字，自动淡出返回主界面。
- 教程不创建比赛、不写入成绩或排行榜，仅在本机记录完成标记；可以退出或重来。已有正式挑战的服务端计时不会因进入教程而暂停。教学使用真实存在的四档曲绘及原图；第二首专门练习别名输入。提示位置说明自动演示 3 秒，教学闪烁延长至 2 秒，扣血后字幕保留 1 秒再淡出。教学计时按步骤推进，正式比赛仍正常计时。

### 难度与挑战设置

以下为界面提供的选项：

| 难度 | 题数 | 每题限时 | 血条 |
| --- | --- | --- | --- |
| EZ | 5／10／20 | 30／60／90 秒 | 隐藏 |
| HD | 5／10／20 | 30／60／90 秒 | 关闭／20HP／50HP |
| IN | 5／10／20／Infinity | 15／30／60 秒 | 关闭／20HP／50HP；Infinity 自动开启 |
| AT | 固定 Infinity | 固定 30 秒 | 强制开启，可选 20HP／50HP |

IN 选中 Infinity 后，关闭血条会退回 5 题。Infinity 按当前全部可用歌曲去重出题，曲库耗尽或血量归零时结束；同一首歌的多个曲绘变体不会在同局重复抽取。

### 猜曲、提示与噪域

- 歌名支持别名、大小写、全半角和空白归一化。判题、计分与血量结算由服务端处理，提交 ID 保证请求幂等。
- HD／IN／AT 的提示按章节范围、身份信息、降低一级题图难度的顺序显示并解锁。EZ 只有范围与身份两项；EZ／HD 的身份提示为章节与曲师，IN／AT 为曲师与画师。提示不延长时间；第 3 条统一显示“得分减少，难度下降”，按降低一档后的上限计算本题实际得分，题目应得满分与结算基准仍保留开局难度。
- 答对后锁定本题，沿斜向边界揭晓原图；题图和原图均通过参与者身份及场次状态鉴权，不公开运行素材目录。
- 当前题图加载完成后，浏览器低优先级预加载下一张曲绘的加密数据；正式切题时获取密钥并显示，避免把下载时间留到下一题。仅缓存下一张，不提前传输原图或歌名；预加载失败时回退到普通题图加载。
- 开局黑屏先生成最多 10 道题，首题下载并解码后才开始计时。答题中后台补足包含当前题在内的 20 道待答题，满额暂停，进入下一题再补充。
- 非主线第一条提示显示包含收录版本的 2～3 个版本范围；已删除曲目标注“已删除”，愚人节曲绘只显示“愚人节曲目/特殊曲绘”。
- 未猜出的歌名显示动态乱码。曲绘、曲名和提交按钮的噪域共用一个顶层画布与渲染器，相邻区域合并，支持覆盖、交互光效与换题退场。
- 提交按钮在最后 5 秒出现粉区，最后 0.8 秒闪烁，到时转为红区。红区覆盖后，点击或按 Enter 只扣 1HP，不提交答案；未被红区覆盖时 Enter 正常提交。
- 悬停在红色噪域上时，音乐和音效一起变闷，每连续停留 2 秒扣 1HP；移出、打开弹窗或切到后台会清零计时。
- 右下角 TIME LEFT 首次点击显示 `SKIP?`，再次点击按超时规则跳过；点击空白或按 Esc 取消确认。确认跳过时噪域先闪烁粉区，0.8 秒后铺满为红区。
- EZ／HD／IN 左上角首次点击展开“放弃？”，再次点击淡黑进入结算。AT 首次点击立即出现闪烁粉区并屏蔽按钮，0.8 秒后转为红色噪域。

### 血量规则

开启血条时满血开局，血量与上限随场次保存。

| 行为 | 血量变化 |
| --- | --- |
| 每次答错 | −1HP |
| 超时／跳过，本题答错 0 次 | −5HP |
| 超时／跳过，本题答错 1 次 | −4HP |
| 超时／跳过，本题答错 2 次及以上 | −3HP |
| 点击已形成的红区／红色提交区按 Enter | −1HP |
| 连续悬停红区，每满 2 秒 | −1HP |
| 答对，使用提示 0／1／2／3 次 | +5／3／2／1HP |

答错和超时扣血分别结算，噪域伤害不计入答错次数。回血不超过上限；曾答错但未使用提示，答对仍回 5HP。血量归零自动结束挑战。扣血时出现轻量边缘红晕与波纹，回血不触发。

### 得分与综合成绩牌

当前计分版本为 `v4-downgrade`：

| 难度 | 单首满分 |
| --- | ---: |
| EZ | 500 |
| HD | 1000 |
| IN | 2000 |
| AT | 3000 |

耗时占 50%：前 1/6 限时不扣分，之后线性扣分，最多扣计分上限的 50%。每次答错扣计分上限的 10%，最多扣 50%；前两条提示不降低上限，第 3 条降低题图和计分上限一档（HD→EZ 500、IN→HD 1000、AT→IN 2000）。题目应得满分和综合牌分母仍按开局难度，AT 降为 IN 后仍以 3000 分作为结算基准。超时、跳过或未猜出记 0 分。

设计分上限为 `B`（默认等于开局难度满分，使用第 3 条提示后为降低一档的满分）、用时为 `t`、限时为 `T`、答错次数为 `n`：

```text
答对得分 = round(B × [1 − 0.5 × clamp((t − T/6) / (5T/6), 0, 1) − min(0.1n, 0.5)])
总分 = 所有单首得分之和
综合得分率 = 答对曲目的实际总分 ÷（答对首数 × 该难度单首满分）
```

`round` 为四舍五入到整数。综合牌只统计答对的曲目，未猜出、超时、跳过均不计入分母；牌面数字是答对首数。

| 综合牌颜色 | 综合得分率 |
| --- | --- |
| 彩 | 100% |
| 金 | ≥95%，＜100% |
| 红 | ≥90%，＜95% |
| 蓝 | ≥80%，＜90% |
| 绿 | ≥70%，＜80% |
| 无牌 | ＜70%，或答对 0 首 |

### 结算与排行榜

- 正常结束先淡入黑屏再进入结算；血量耗尽时立即黑屏，耗尽动效位于黑屏上方。无需点击“查看结果”。
- 按实际挑战曲目生成结算卡片，显示单首得分、猜测次数和耗时，下方显示总分。保留三行滚动范围，不显示滚动条；越接近浏览器上下边缘，卡片越模糊。
- 未猜出的曲绘保留抽象图，曲名显示动态乱码；点击曲绘可揭晓正确曲绘和曲名，不改变本场成绩。
- 已结束的 Infinity 挑战可进入综合成绩页：× 不公布并返回主界面，✓ 公布后返回主界面。成绩默认私有，历史记录保留；主动放弃或服务重启中断的挑战保留结算，不参加发布。
- 排行榜收录明确公布的 IN／AT 单人 Infinity 成绩，按开局难度、20HP／50HP、每题时限分别比较，保留每位玩家在该条件下的最高分。游客与注册账号均可上榜，血量耗尽的正常结束成绩也可公布。
- 排行榜包含 `HATE_GEOPELIA` 参考角色彩蛋；旧规则成绩在同一榜单保留，排名显示“--”；新规则成绩重新排名，公布后替换该玩家同条件的旧榜单成绩。每日挑战已移除。

### 音频与动效

音频位于 `apps/web/public/audio/phigros-4.0.1/`，来源、事件映射、剪辑范围和 SHA-256 见该目录的 [说明](apps/web/public/audio/phigros-4.0.1/README.md) 与 [清单](apps/web/public/audio/phigros-4.0.1/manifest.json)。音乐和音效音量独立保存，交互音效默认开启；已保存的个人开关设置会保留。

- 主界面、排行榜、设置共用 `ChapterSelect0` 循环音乐，页签切换不重播。
- 猜曲绘时循环播放第九章里包氛围音乐，切题保持播放进度。
- 结算按 EZ／HD／IN／AT 播放对应 `LevelOver0／1／2／3`，从黑屏揭开结算画面时开始，综合成绩页连续播放。
- 切下一张曲绘使用 Tap5；答对使用“演绎转场音_1”，答错、超时和噪域伤害导致血量耗尽使用“课题组开始游戏音效”；确认跳过使用“歌曲详情关闭”。普通噪域出现、闪烁和未致命的点击伤害不单独发声。
- 难度选择与确认过场使用同一 DS 音轨的剪辑段；选择段带自然衰减尾响，确认段去掉开头残留回响。退出阶段收掉声音，不补播刷新前的操作。

难度、血条和结算的运动参数根据参考素材测量，相关界面由代码绘制；噪域使用项目内的噪声视频纹理。[参考与测量说明](docs/REFERENCE-MOTION.md) 记录复刻边界，`tools/healthbar-review.html` 和 `tools/results-review.html` 可用于开发预览。

## 本机开发（无需 Docker）

需要独立管理数据库时，先运行：

```powershell
npm.cmd ci
npm.cmd run db:local
```

该终端启动 PostgreSQL，监听 `127.0.0.1:55432`，数据保留在 `storage/local-db/`。另开终端，将 `.env.example` 复制为 `.env`，再把 `storage/local-db/database.env` 的 `DATABASE_URL` 填入 `.env`。开发环境保持 `TRUST_PROXY=0`，前端使用 5174 时设置 `PUBLIC_ORIGIN=http://localhost:5174`。

```powershell
npm.cmd run db:migrate
npm.cmd run assets:catalog
npm.cmd run dev
```

另开终端运行 `npm.cmd run dev:web`。就绪检查为 `http://localhost:3000/api/health/ready`。不需要独立配置时，使用前面的 `preview:game` 即可。

## 导入歌曲素材

仓库跟踪游戏所需的曲库源文件，运行图片由导入工具生成：

```text
storage/corpus/catalog.json       351 组曲绘与 339 首歌曲的对应关系
storage/corpus/prepared/          351 组仅引用 Raw/EZ 的导入清单
storage/corpus/source/            351 张 EZ、351 张 Raw
storage/generated/                按题实时生成的可回收 SVG 缓存
storage/assets/                   本机生成的鉴权运行图片（不跟踪）
```

添加歌曲时，复制 `examples/song.manifest.json`，填入稳定的歌曲 UUID、曲名、别名、版本与四档文件路径。路径相对于 manifest 所在目录；示例的歌曲与路径只是占位。

```powershell
npm.cmd run assets:import -- E:\素材\song.manifest.json
```

- 只需准备原图与 EZ。EZ 展示图保持原有导入参数，HD／IN／AT 从 EZ 基础图按种子实时生成；当前题与降档提示成组准备，详见 [实时题图](docs/DYNAMIC-ARTWORK.md)。
- SVG 只接受静态图形、路径、渐变与裁切，拒绝脚本、外链、嵌入位图、文本等内容；上限为 2MiB、15,000 元素、64 层。
- 同一变体的四档版本以事务切换，相同版本禁止覆盖；旧版本保留，进行中的挑战继续引用原版本。导入中断可能留下无引用文件，清理前应核对数据库。
- 固定题数不能超过相应难度的可用歌曲数。`original` 指定揭晓原图，`variant` 区分同歌曲绘变体；章节、曲师与画师资料用于提示。
- 社区别名在本地判题，可通过 `npm.cmd run aliases:sync` 按需同步；来源与许可记录位于 `data/providers/phi-plugin/`。

更完整的素材来源、去杂色和描摹参数见 [docs/ASSETS.md](docs/ASSETS.md)。
